# BarForge — shtanga ishlab chiqarish hisoblagichi

Telefon va kompyuterda ishlaydigan o‘zbekcha Vue 3 PWA.

## Ishga tushirish

```bash
npm install
npm run dev
```

Kompyuterda `http://localhost:5174/` ni oching. Telefon va kompyuter bir xil Wi-Fi tarmog‘ida bo‘lsa, terminaldagi Network manzilidan foydalaning.

## Hisoblash

- Asl jadvaldagi 2–40 kg shtangalar uchun 39 ta spetsifikatsiya ishlatiladi.
- Har bir shtangaga jadvalda ko‘rsatilgan uzunlikdagi **1 ta dasta** kerak.
- Toshlar jadvalda bitta tomon uchun ko‘rsatilgan, dastur ikki tomonni hisoblaydi.
- Har bir tomondagi eng kichik tosh rezbali, qolganlari oddiy.
- PDF tugmasi A4 hisobotni **to‘g‘ridan-to‘g‘ri yuklab oladi**, chop etish oynasini ochmaydi.
- Saqlangan buyurtmalar shu qurilmaning brauzer xotirasida saqlanadi; boshqa qurilmalarga sinxronlanmaydi.

## Ishlab chiqarish versiyasi

```bash
npm run build
npm run preview
```

Telefonlarga o‘rnatiladigan PWA sifatida tarqatish uchun HTTPS orqali hostingga joylang.
